# Risorse per le Pagine Web delle Lezioni

Questo repository contiene i file di base utilizzati per la creazione
delle pagine web delle lezioni.

## Struttura del progetto

-   **HTML** File di struttura principale delle pagine.

-   **CSS**

    -   style.css: stile generale
    -   theme.css: gestione tema chiaro/scuro

-   **JavaScript**

    -   theme.js: gestione interattività e cambio tema

-   **Prism**

    -   prism.css
    -   prism.js Evidenziazione sintattica del codice.

-   **Assets** Icone, immagini e favicon.

## Utilizzo

1.  Copiare il template HTML.
2.  Inserire i contenuti della lezione.
3.  Verificare i percorsi dei file.
4.  Pubblicare su hosting/GitHub Pages.

## Obiettivo

Fornire una base riutilizzabile, coerente e accessibile per la didattica
digitale.
